# Клиент API кофейных напитков

Небольшой учебный проект на Python для работы с API SampleAPIs Coffee. Программа получает список напитков, создаёт тестовый напиток, изменяет его и удаляет. Для запросов используется библиотека `requests`.

## Требования

- Python 3.10 или новее.
- Доступ к интернету.

## Запуск

В PowerShell из папки проекта выполните:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

Программа выведет результаты запросов к API в консоль.
